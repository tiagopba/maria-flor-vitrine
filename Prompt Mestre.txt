# 1. CONTEXTO DO NEGÓCIO

A Maria Flor é uma loja física de moda feminina com muitos anos de atuação e uma audiência relevante no Instagram.

O processo comercial atual funciona principalmente assim:

1. chegam novidades constantemente;
2. são produzidas fotos e provadores;
3. os produtos são publicados principalmente nos Stories do Instagram;
4. as clientes acompanham os Stories;
5. quando se interessam, entram em contato pelo WhatsApp;
6. uma vendedora confirma disponibilidade;
7. a venda é concluída diretamente pelo atendimento.

Esse modelo funciona comercialmente.

O problema é que:

* Stories desaparecem em 24 horas;
* produtos antigos ficam difíceis de encontrar;
* clientes não conseguem navegar facilmente por categorias;
* uma cliente pode lembrar de uma peça dias depois e não encontrá-la;
* o Instagram não funciona bem como catálogo permanente;
* perdemos dados sobre o interesse real das clientes;
* não conseguimos medir adequadamente quais produtos despertam mais desejo;
* não conseguimos fazer remarketing de forma tão eficiente quanto poderíamos.

Já houve tentativa de trabalhar com e-commerce tradicional, mas o modelo não se encaixa perfeitamente na operação.

A loja possui:

* estoque físico;
* giro muito rápido;
* vendas presenciais;
* produtos que podem estar temporariamente fora da loja;
* mercadorias consignadas/condicionais;
* possibilidade de divergência entre estoque registrado e disponibilidade física real.

Portanto:

# REGRA DE NEGÓCIO Nº 1

**A plataforma NÃO deve funcionar inicialmente como um e-commerce tradicional e NÃO deve garantir estoque ao consumidor.**

Não criar inicialmente:

* checkout;
* carrinho tradicional;
* pagamento online;
* reserva automática de estoque;
* baixa automática de estoque;
* promessa de disponibilidade;
* integração obrigatória com estoque;
* cálculo de frete;
* emissão fiscal;
* ERP.

O objetivo do MVP é:

> MOSTRAR → GERAR DESEJO → ORGANIZAR → RASTREAR → LEVAR PARA O WHATSAPP → VENDEDORA CONFIRMA → VENDA.
